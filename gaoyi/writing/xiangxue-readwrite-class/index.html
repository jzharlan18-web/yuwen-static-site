使用说明

把“转变”写成一段路｜《哦，香雪》课堂文本研读 · 单文件离线版

切换与阅读

切换活动／环节顶部三个活动按钮；左侧环节列表（带时间刻度，当前项左侧蓝线＋实心方块）
上一屏／下一屏底部按钮，或 ← → PageUp PageDown 空格。分屏按句子边界切，不切断句子
字号底部「字号－／＋」，或 - =。范围 32—56px，默认 40px。改字号后标记仍落在原句
专注阅读底部或顶部「专注阅读」，或 F。收起左侧与低频工具，给正文让出宽度
收起问句问题下方「收起问句」／「展开问句」，字大时优先给正文空间

回看与返回（本页关键交互）

打开回看正文下方「回看」行，或教师归纳旁的「回到原句」。覆盖层在本页内部打开，不跳外站
返回覆盖层右上「返回…」按钮，或 Esc。逐层返回，不回首页
连续回看回看中可继续打开别的段落，返回时先回上一层，再回原环节
状态恢复返回后恢复原环节、原分屏、焦点段落、字号、专注状态与归纳显示；教师先前做过的标记全部保留
快捷键边界回看外的 Esc 只退出专注阅读，不推进课堂；选中文本时不触发翻屏

标记

拖选正文后直接按 H 高亮、U 下划线；Z 撤销最近一笔；X 进入取消单笔后点击标记，Esc 退出。无需打开面板。回看中同样有效，独立检测时禁用。清除本段只使用按钮。

打开工具顶部「标记」，或 M。面板打开时正文会自动收窄让出右侧空间，不会压住字
高亮／下划线在正文里按住鼠标拖选一段文字（可跨行），再点「高亮」（淡黄）或「下划线」（深蓝）。默认不预置任何标记
撤销／取消单笔「撤销」去掉最近一笔；「取消单笔」后面板自动收起（否则挡住正文），顶部按钮变「标记·取消中」，正文里每一笔变成可点状态，点哪笔去哪笔（不改原文），再点顶部「标记」退出
清除本段标记去掉当前段落的全部标记，原文内容与段落结构不变
跨环节同一段落在独立圈读、讨论、对读、回看中共用同一份原文与同一批标记；回看覆盖层内也能标记，此时面板移到右下角，不挡「返回」按钮
提示没选中就点 → 提示先选中；选区与已有标记重叠 → 提示不能重叠。提示约 2 秒后自动恢复

独立检测

C01 进入时关闭原文、回看、标记、作文金句与备用研读；学生收起课文、旧作文和活动单，只看新题独立完成。教师切回前两个活动需确认

其他

复制原文直接选中正文复制，得到纯文字，不含网页编号与 HTML 转义
新课开始清空本机保存的标记与阅读位置，从默认未标记状态重新开始（会先确认）
离线使用本文件为单文件网页，双击可在 Chrome／Edge 打开，断网时切换、回看、返回、标记、字号均可用
